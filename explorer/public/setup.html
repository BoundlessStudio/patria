Map sources

Patria opens in Google Photorealistic 3D, which uses aerial imagery to render buildings and trees where 3D coverage is available. Use the layers menu for the muted styled map, a flat map, or overhead satellite imagery. Street View opens Google's panorama from any map layer.

Sign in on the hosted site to discover places. Photon supplies location search and nearby places from OpenStreetMap contributors. Suggested walks link to Google Maps for directions.

The app uses a website-restricted Maps JavaScript browser key. For local setup, put the key in GOOGLE_MAPS_BROWSER_KEY in .env and run npm run dev.

Live traffic

Turn on Live traffic in the map layers menu to see current road conditions where Google has coverage. From Photorealistic 3D, Patria switches to the styled map to show the traffic overlay. The colors represent traffic flow. Published vehicle counts are kept separately as historical data.
